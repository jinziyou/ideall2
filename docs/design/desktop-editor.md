# GPUI 桌面笔记编辑器

> 状态：现行。本文描述桌面笔记编辑器已经实现的 Notion 式编辑闭环。工作台整体视觉见
> [ui-style.md](ui-style.md)，组件边界见
> [desktop-components.md](desktop-components.md)。

## 产品边界

桌面编辑器以“原生块为交互单位、Markdown 为可逆兼容投影、Plate JSON 为持久化格式”。
标准文本块在编辑时使用纯文本与 byte-range marks，Markdown 分隔符不会出现在输入界面；
投影层只负责跨端兼容、受保护块校验和持久化往返。
目标是逐步覆盖 Notion 文档编辑器的等价能力，同时保持 ideall 的本地优先、跨端一致和
未知数据不丢失约束。数据库视图、多人实时协作、组织权限和第三方云集成属于独立子系统，
不能假装成已经完成的编辑器能力。

暂不支持的 Plate 块必须继续显示为受保护卡片，并原样保留 JSON；不能用外观相似但不可逆的
控件冒充支持。

## 已实现能力

| 范围 | 能力 |
| --- | --- |
| 文档画布 | 最大 760px 的浅色居中正文画布、类型眉题、大标题输入、700 ms 自动保存、每文档块与光标恢复 |
| 阅读与编辑 | 每个 Plate 块对应独立 GPUI 实体；编辑视图的所有可编辑块始终挂载原生输入，单击即可精确放置光标；阅读视图复用同一富文本实体的只读模式，保留选区、复制和链接跳转并拒绝写入 |
| 基础块 | 正文、H1/H2/H3、引用、项目列表、编号列表、待办、代码块、分隔线 |
| 高级块 | Callout、可展开 Toggle、块公式、HTTP(S) 网页书签；均有真实 Plate 类型、斜杠命令和原生交互 |
| 输入语义 | Enter 拆分块、自动聚焦并延续列表/待办，空列表 Enter 退出列表，Shift+Enter 插入块内软换行；支持自动折行和 `# `、`- `、`1. `、`[] `、`> `、围栏、分隔线快捷转换 |
| `/` 命令 | 在当前块输入 `/` 后按中文名、英文别名或用途筛选；Enter 选择第一项，也可鼠标选择 |
| 页面提及 | 输入 `@` 按标题筛选本地页面；Enter 或鼠标插入严格的内部页面链接，双击提及跳转，目标页面底部显示反向链接 |
| 行内格式 | 粗体、斜体、删除线、行内代码、九色文字与九色背景高亮使用原生选区 marks；HTTP(S) 链接可新建、修改和取消，保存时写回真实 Plate marks/link 节点 |
| 选区交互 | 鼠标或键盘选中文字后显示紧凑浮动格式条；主格式条与浮动条均提供带当前状态的颜色菜单；系统剪贴板提供纯文本，ideall 内部粘贴恢复富文本 marks |
| 块操作 | Shift 连续选择、Ctrl/⌘ 增减选择、拖拽重排、手柄菜单、前置插入、批量复制/重复/删除、上移、下移、待办完成切换、列表缩进与减少缩进 |
| 文档工具 | 44px 单行格式栏、查找、跨块定位、跨块全部替换、手动保存、面包屑栏「阅读/编辑」分段切换、底部状态栏（模式/格式/行列/字符数/保存状态） |
| 历史 | 文本和结构变化进入统一的有界文档快照历史；工具栏撤销/重做可恢复删除、移动和类型转换 |

多行引用和代码围栏作为一个块移动。删除、复制、转换与移动均直接作用于块集合，不再通过
整篇 Markdown 文本推测当前块。保存仍经过 application 的受保护块校验。手动保存不会重新
加载当前文档，因此不会丢失输入焦点、光标或主动选择的编辑/阅读模式。

块手柄支持拖到任意块之前或画布末尾；选择一个手柄后 Shift 点击另一个手柄会选择连续范围，
Ctrl/⌘ 点击用于增减离散选择。复制写入系统剪贴板，重复在当前文档内生成新块；批量删除作为
一个文档历史步骤撤销。选区包含受保护块时，重复和删除整组拒绝执行，避免复制兼容占位。
单击手柄打开块菜单，拖动同一手柄仍执行排序；菜单复用已经过测试的移动、复制、重复和删除
命令，不维护第二套块状态。

页面提及保存为 `ideall://node/<id>` 的严格内部链接，只有受限字符、无路径穿越的本地节点 ID
可以进入 Plate `a` 节点。候选排除当前页面并优先标题前缀匹配；已插入的链接 mark 不会再次
触发 `@` 菜单。反向链接从本地 Plate 链接节点计算，因此代码块中的相似文本不会产生假引用。

颜色使用受控的九色语义色板，前景色和背景高亮互相独立且同类颜色互斥。编辑器只显示最终
文字，不显示兼容标记；Plate 分别写入标准 `color` 与 `backgroundColor` 叶属性。Markdown
兼容投影使用严格白名单的内联标签，字面标签会自动转义，重新加载、撤销和 ideall 内部复制
粘贴都不会丢失颜色。

当前 GPUI 剪贴板抽象只向系统公开纯文本或图片，附加 metadata 仅用于同一应用内部恢复 marks；
它不能写入 `text/html` 或 RTF MIME。跨应用富文本复制必须增加 macOS、Windows 与 Linux
原生剪贴板适配层，在该适配完成前仍按兼容矩阵 B3 标记为待实现。

Callout 图标可以循环切换；Toggle 在阅读和编辑视图都能展开或收起；书签以卡片显示并在打开
前重新校验 URL scheme；公式使用独立块保存。四类高级块都有明确结束标记，缺失结束标记时
application 拒绝写入，避免吞并后续内容。

| 删除线 | `⌘ ⇧ S` | `Ctrl Shift S` |

| 重复所选块 | `⌘ ⇧ D` | `Ctrl Shift D` |
| 复制所选块 | `⌘ ⇧ C` | `Ctrl Shift C` |

## 代码结构

```text
ideall-application/src/
├── note_edit.rs       # 跨端块、斜杠命令和安全校验
├── note_rich_text.rs  # 纯文本、range marks、语义色板、内部提及与 Markdown 可逆投影
└── workspace.rs       # 本地 Plate 反向链接查询

ideall-desktop/src/editor/
├── mod.rs        # 输入、草稿和会话
├── blocks.rs    # 原生块种类、Markdown 投影解析与回写
├── commands.rs  # 块输入事件、结构命令、历史、状态反馈
├── actions.rs   # 标签动作
├── rich_input.rs # GPUI 富文本、IME、多行折行、选区、剪贴板、提及与 UTF-8/UTF-16 换算
└── view.rs       # 块画布、手柄菜单、斜杠/提及菜单、反向链接与 Engine 视觉
```

共享层只处理 `String`、byte range 和枚举，不依赖 GPUI。原生输入把系统的 UTF-16 选区转换为
UTF-8 byte range，以 grapheme 边界移动光标，并将 IME marked range、鼠标选区和自动折行结果
映射到同一份文档。字面 Markdown 标点在兼容投影中自动转义，重新加载后仍是普通文本。

## 数据安全不变量

1. `⟦ideall:受保护块:…⟧` 所在块不能格式化、复制、删除或应用行内标记。
2. 未闭合代码围栏或高级块标记时拒绝重排、复制和删除，避免把后续正文误判为同一块。
3. 代码围栏内部拒绝普通块与行内格式转换。
4. 未修改的已知块保存时复用原始 Plate JSON，包括 marks、插件属性和稳定块 ID。
5. 工具栏只对可编辑 Note 生效；文件文本编辑、Bookmark、回收站和只读内容不显示该工具栏。
6. 外部链接和书签仅接受 HTTP(S)；内部提及仅接受严格的 `ideall://node/<id>`。其他 scheme
   保持普通文本，不生成可点击节点。链接面板失焦或校验失败时不能写入占位 URL。
7. 标题、格式条和正文使用同一居中轴；格式条固定为 44px 单行，低频块类型与块操作进入
   下拉菜单，不能依赖不可见的横向溢出隐藏核心命令。
8. 列表、引用、代码块和块操作使用紧凑符号时必须提供中文 tooltip，不能只依靠图形猜测行为。
9. 阅读视图复用同一原生富文本实体的只读模式，不建立第二份正文；系统输入与剪贴板粘贴不能
   绕过只读守卫。

## 验收

自动门禁覆盖块投影往返、Unicode 光标换算、斜杠筛选、H3 转换、块移动/复制/删除、
待办与缩进、行内标记切换、字面 Markdown 标点往返、受保护块和未闭合围栏。发布前仍需人工
确认：

1. 中文 IME 组合输入期间菜单不会错误提交。
2. 鼠标选中文本后点击行内格式，标记包裹正确且撤销恢复原选区内容。
3. 窄窗口的两行工具栏仍显示全部核心命令，斜杠菜单不会遮挡当前输入到无法继续。
4. 自动保存、切换标签、关闭窗口后重新打开，Plate 块类型与顺序保持一致。
5. 长段落自动折行后，鼠标定位、跨行选区、上下方向键和 IME 候选位置一致。
6. Shift+Enter 重启后仍是同一 Plate 块；在 ideall 内复制粘贴选区可恢复 marks，粘贴到外部
   应用只暴露纯文本。
7. 点击非活动块一次即可定位光标；`@` 候选点击不穿透到底层块，插入后菜单立即关闭；双击
   提及跳转到目标页面，目标页面显示来源反向链接。
