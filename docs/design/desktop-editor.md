# GPUI 桌面笔记编辑器

> 状态：现行。本文描述桌面笔记编辑器已经实现的 Notion 式编辑闭环。工作台整体视觉见
> [ui-style.md](ui-style.md)，组件边界见
> [desktop-components.md](desktop-components.md)。

## 产品边界

桌面编辑器以“块为主要操作单位、Markdown 为可逆编辑投影、Plate JSON 为持久化格式”。
目标是提供与 Notion 相近的文档编辑习惯，同时保持 ideall 的本地优先、跨端一致和未知数据
不丢失约束。

这里的“Notion 式”指文档编辑体验，不表示复制 Notion 的云协作、数据库视图、评论、权限或
第三方服务。暂不支持的 Plate 块必须继续显示为受保护指纹占位，不能用外观相似但不可逆的
控件冒充支持。

## 已实现能力

| 范围 | 能力 |
| --- | --- |
| 文档画布 | 最大 800px 的浅色居中正文画布、类型眉题、大标题输入、700 ms 自动保存、每文档光标恢复 |
| 基础块 | 正文、H1/H2/H3、引用、项目列表、编号列表、待办、代码块、分隔线 |
| `/` 命令 | 在新行输入 `/` 后按中文名、英文别名或用途筛选；Enter 选择第一项，也可鼠标选择 |
| 行内格式 | 粗体、斜体、删除线、行内代码、HTTP(S) 链接；保存时写回真实 Plate marks/link 节点 |
| 块操作 | 上移、下移、复制、删除、待办完成切换、列表缩进与减少缩进 |
| 文档工具 | 居中面板式格式条、带说明的紧凑图标、查找、全部替换、手动保存、编辑/只读状态、行列/换行符/语言状态 |
| 历史 | 工具栏变更通过 GPUI 输入事务写入，不重载整篇正文，可使用系统撤销恢复 |

多行引用和代码围栏作为一个块移动。复制相邻引用时插入空段落以保持两个 Plate 块的边界。
删除块属于可撤销编辑；保存仍经过 application 的受保护块校验。

## 快捷键

| 动作 | macOS | Windows / Linux |
| --- | --- | --- |
| 粗体 | `⌘ B` | `Ctrl B` |
| 斜体 | `⌘ I` | `Ctrl I` |
| 删除线 | `⌘ ⇧ S` | `Ctrl Shift S` |
| 行内代码 | `⌘ E` | `Ctrl Alt E` |
| 上移 / 下移块 | `⌘ ⌥ ↑/↓` | `Ctrl Alt ↑/↓` |
| 复制块 | `⌘ ⇧ D` | `Ctrl Shift D` |
| 查找 / 替换 | `⌘ F` / `⌘ ⌥ F` | `Ctrl F` / `Ctrl Alt F` |
| 保存 | `⌘ S` | `Ctrl S` |

格式和块快捷键仅在笔记正文拥有焦点时生效，不会修改 Explorer 选择或标题输入。

## 代码结构

```text
ideall-application/src/note_edit.rs
  └── 跨桌面/移动共享的块、斜杠命令、行内格式和安全校验

ideall-desktop/src/editor/
├── mod.rs       # 输入、草稿、会话、UTF-8/UTF-16 光标换算
├── commands.rs  # GPUI 输入事务桥接、状态反馈
├── actions.rs   # 标签动作
└── view.rs      # EditorMode 与 Engine 视觉
```

共享层只处理 `String`、byte range 和枚举，不依赖 GPUI。桌面桥把 GPUI 的 UTF-16 选区转换为
UTF-8 byte range，并只替换最小变化区间；这同时保护 Unicode 光标位置和输入组件撤销历史。

## 数据安全不变量

1. `⟦ideall:受保护块:…⟧` 所在块不能格式化、复制、删除或应用行内标记。
2. 未闭合代码围栏时拒绝重排、复制和删除，避免把后续正文误判为代码。
3. 代码围栏内部拒绝普通块与行内格式转换。
4. 未修改的已知块保存时复用原始 Plate JSON，包括 marks、插件属性和稳定块 ID。
5. 工具栏只对可编辑 Note 生效；文件代码编辑、Bookmark、回收站和只读内容不显示该工具栏。
6. 新建链接仅接受 HTTP(S)；不安全 scheme 保持普通文本，不生成可点击 Plate link。
7. 标题、格式条和正文使用同一居中轴；格式条必须保留横向滚动能力，不能因窗口变窄重排成纵列。
8. 列表、引用、代码块和块操作使用紧凑符号时必须提供中文 tooltip，不能只依靠图形猜测行为。

## 验收

自动门禁覆盖 Unicode 光标换算、斜杠筛选、H3 转换、块移动/复制/删除、待办与缩进、
行内标记切换、受保护块和未闭合围栏。发布前仍需人工确认：

1. 中文 IME 组合输入期间菜单不会错误提交。
2. 鼠标选中文本后点击行内格式，标记包裹正确且撤销恢复原选区内容。
3. 长文档工具栏可横向滚动，斜杠菜单不会遮挡当前输入到无法继续。
4. 自动保存、切换标签、关闭窗口后重新打开，Plate 块类型与顺序保持一致。
