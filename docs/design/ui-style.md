# UI 视觉规范——清氧工作台

> 状态：现行。本文是桌面视觉的治理规范，与 `native/apps/ideall-desktop` 当前实现
> 逐条对应。默认分支只包含 GPUI UI；旧 Next.js/Tauri V2 冻结在 `legacy/tauri-v2`。
> 桌面组件边界见 [desktop-components.md](desktop-components.md)。

## 1. 设计方向

桌面端采用克制、低噪声的浅色 AI 原生工作台（方向 A「清氧工作台」）。通过紧密网格、
有意留白、分层灰阶与智能绿色，保留 ideall 的本地文件树，并形成导航、资料库、内容与
Agent 四区信息架构：

- 浅色为默认且是当前唯一承诺的完整主题。
- 顶栏、侧边导航栏、活动/目录栏、内容工作区和常驻 Agent 形成稳定框架。
- 面板通过连续浅色表面与 1px 分隔线建立边界；紧凑的是框架，不压缩文档正文的呼吸感。
- 卡片和面板坚持 border-first：白底、1px 分隔、圆角 12，无常驻大阴影；浮层才允许轻投影。
- 智能绿只点在关键路径：当前项、焦点、主操作、保存状态与命中高亮。
- 默认只显示当前任务需要的操作；低频能力进入上下文菜单、斜杠菜单、下拉或快捷键。
- 文件浏览与编辑是第一优先级；Agent 默认保持紧凑并可折叠，不能挤占编辑主区域。
- 打开方式属于当前文件的 Engine 选择，不为每个 Engine 增加一级导航。

移动端使用单列任务流和底部导航，不照搬桌面 IDE 布局；共享的只有语义文案和无 GPUI 类型
的设计 Token。

## 2. Token 单一事实来源

生产颜色定义位于
`native/crates/ideall-presentation/src/lib.rs::color::desktop`。桌面代码只引用语义常量，
不得在视图中新增散落的 RGB 字面量。唯一获准的字面量是 `#d39a27`（未保存点与关注源图标的
琥珀色），复用同一常量定义处。

| Token | 当前值 | 用途 |
| --- | --- | --- |
| `CANVAS` | `#f4f6f4` | 窗口底色与页面留白 |
| `SURFACE` / `EDITOR` | `#ffffff` | 面板、主内容与编辑器 |
| `SURFACE_MUTED` / `TOOLBAR` | `#f8faf8` | 工具条、资料库和 Agent 背景 |
| `EDITOR_GUTTER` | `#f7f8f6` | 编辑器次级区域 |
| `INK` | `#1b211e` | 主文本 |
| `INK_MUTED` | `#6a726d` | 次级文本 |
| `INK_FAINT` | `#9aa29c` | 元信息与占位 |
| `BORDER` | `#e4e8e5` | 常规分隔 |
| `BORDER_STRONG` | `#cdd4cf` | 活动边界与拖拽 |
| `ACCENT` | `#16825d` | 当前项、焦点和主操作 |
| `ACCENT_SOFT` / `SELECTION` | `#e6f4ec` / `#ddf0e5` | 轻量选中背景 |
| `RAIL` / `ACCENT_ON_RAIL` | `#f7f9f6` / `#16825d` | 浅色纵向导航和当前项 |
| `HOVER` | `#eff2f0` | 悬停反馈 |

圆角由 gpui-component 主题统一收口：`radius = 8`、`radius_lg = 10`；树行等小控件用 6，
页面卡片用 12，全圆角只用于搜索胶囊、kbd 小片、chips 与上下文 chip。

应用启动必须显式选择 `ThemeMode::Light`。未来增加暗色时，应先补齐整套语义 Token、编辑器
高亮和 WebView/系统控件对齐，再提供切换入口；不得把局部颜色反转称为暗色支持。

## 3. 桌面布局

```text
┌────────────────────────────── 顶栏 / 本地状态 ───────────────────────────────────┐
├── 导航栏 ─┬────── 活动 / 资料库 ──────┬──────── 标签内容工作区 ────────┬── Agent ┤
│ 五个分区  │ 搜索、目录与文件树        │ 多文件时显示轻量标签条           │ 上下文  │
│           │ 节点操作、收集箱、回收站  ├─────────────────────────────────┤ 对话    │
│           │ 可折叠、可调整宽度        │ Editor / Preview / Browser Engine│ 审计    │
└───────────┴───────────────────────────┴─────────────────────────────────┴─────────┘
```

- 一级导航固定为“我的 / 活动 / 浏览 / 应用 / 设置”。
- 主窗口首次打开时以 1280×820 为首选尺寸，在主显示器中居中；显示器较小时先收缩到可见
  范围再计算中心，不能生成屏幕外的默认坐标。Linux X11 必须使用 RandR 的真实 monitor，
  不能把多屏联合 root screen 当成主显示器；未标记 primary 时使用第一个活动 monitor。
  Wayland compositor 可按协议接管最终位置。
- Browser Engine 不构成一级导航项；其挂载状态以组件文档为准。

### 顶栏（48px）

三段式。左组：资料库开关、wordmark「ideall」与眉题「LOCAL WORKSPACE」（10px、大写、
INK_FAINT，左侧 1px 分隔）。中间：340px 全圆角搜索胶囊——SURFACE_MUTED 底、放大镜图标、
「搜索全部内容」与右侧白底 ⌘K kbd 小片，点击等同搜索动作，hover 仅加深描边。右组：
ACCENT 状态点 + 12px INK_MUTED 状态文案（本地已保存 / 正在保存 / 真实错误）。

### 侧边导航栏（56px）

- 顶部品牌 tile（圆角 10、ACCENT_SOFT 底、ACCENT 品牌图形），上组为工作台、最近、浏览、
  Agent，设置钉在底部并以 1px 分隔线区隔。
- 36px 图标按钮、圆角 8；当前项 = ACCENT_SOFT 底 + ACCENT 图标 + 左侧 2px ACCENT 指示条；
  非当前项 RAIL_MUTED 图标，hover HOVER 底。只负责切换分区，不承载目录操作。

### 活动 / 资料库（272px，220–520 可调并持久化）

- 标题行「资料库」（13px 半粗）+「＋」幽灵按钮（新建页面、文本、目录、书签与导入）；
  搜索框白底、1px BORDER、圆角 8，聚焦时描边加深。
- 目录交互借鉴 Notion：“私有页面”“收集箱”“回收站”是同级树根，文件与目录按父子关系
  缩进、展开和折叠。收集箱带未整理计数徽标，其子树不在“私有页面”重复出现；整理收集箱
  即常规移动操作，不设第二套机制。
- 分组标题（私有页面 / 最近更新等）11px 半粗 INK_FAINT；树行高 28px、圆角 6，左右留
  8px 内边距，hover HOVER；选中行 SELECTION 底 + INK 字。
- 类型图标着色：书签 ACCENT、关注源琥珀（`#d39a27`）、其余 INK_MUTED；选中行图标
  ACCENT。文件夹节点的右键菜单在当前目录创建子项，重命名与删除进入右键菜单和快捷键。

### 标签内容工作区

- 编辑区始终获得剩余空间，最小尺寸和溢出必须显式处理。
- 标签条约 40px，仅在打开多个文件时出现。活跃标签：白底、上圆角 8、与栏底线融合并带
  下缘 2px ACCENT 线、dirty ● 或关闭 ×；非活跃标签 INK_MUTED 透明底，hover HOVER 圆角 8；
  不使用贯穿整栏的重色块。
- 笔记壳：面包屑 11px（父目录 / 当前标题）；右端为撤销/重做、「阅读/编辑」分段胶囊
  （SURFACE_MUTED 容器、当前项白色 pill）与查找。文档大标题 30px 半粗，上方 11px 类型
  眉题，保存状态收口到标题旁的状态点与顶栏，不为笔记另设底部状态行。
- 笔记编辑态使用 44px 单行格式栏：块类型全圆角胶囊下拉、28px 圆角 6 控件、组间 1px 竖
  分隔线、激活态 ACCENT_SOFT 底 + ACCENT 字；低频块类型与块操作进入下拉，与当前块无关的
  列表操作不显示。阅读态不渲染格式栏，分段切换因此必须留在面包屑栏。
- Note 在工作台内使用最大 760px 的居中文档画布和块操作；文件、Preview 与
  Browser 继续使用满宽 Engine 区域。编辑行为见
  [desktop-editor.md](desktop-editor.md)。
- 活动、浏览、搜索、收集箱和回收站在未选择文档时显示真实集合列表与空态，不复用欢迎页；
  列表项可直接打开，浏览页可直接新建书签。搜索结果页在标题下提供类型过滤 chips
  （全部/笔记/书签/文件/关注源/对话，26px 全圆角，当前项 ACCENT_SOFT 底 + ACCENT 字），
  结果行为两行：标题行 + 12px 摘要行（命中词 ACCENT 半粗，正文未命中时回退为正文前
  120 字符）。
- 设置、应用与欢迎页使用统一的页面卡片：白底、1px BORDER、圆角 12、无常驻投影，hover
  BORDER_STRONG；页面标题 16–20px 半粗；输入控件白底圆角 8；主操作 ACCENT 底圆角 8
  （hover ACCENT_HOVER），每局部区域最多一个主操作。

### Agent 面板（320px，可折叠为 42px）

- 面板与输入区底色 SURFACE_MUTED。头部「Ideall Agent」+ 就绪/处理中状态点与三个幽灵
  图标按钮（新建对话、历史与设置、收起）。
- 上下文 chip 全圆角：未附加 = 1px 描边 + INK_FAINT 文案；已附加 = ACCENT_SOFT 底 +
  ACCENT 图标文字。当前文档必须由用户点击附加，切换文档即自动解除；附加正文只进入当次
  模型上下文，不复制到持久化对话。
- 用户消息 = 白底圆角 12 + 1px BORDER 气泡；助手消息去气泡融入底色并按 Markdown 渲染；
  工具消息 = MESSAGE_TOOL 底圆角 8 + 工具图标 11px；审计卡 = 白底 1px BORDER 圆角 12，
  盾形图标 +「写操作审计」半粗 + 次数小 chip + 最近一条摘要。
- 输入框白底圆角 12、1px BORDER、聚焦描边加深；发送按钮 28px 圆形 ACCENT 底白色 ↑；
  底部模型与 `Ctrl/⌘ Enter` 提示 11px INK_FAINT。写操作在执行前确认，并记录到本地审计。
- 非笔记 Engine（文本、网址、只读、外部应用）使用 30px 状态栏：SURFACE_MUTED 底、顶部
  1px BORDER、11px INK_MUTED 分段信息与右侧保存状态。

## 4. 排版与间距

- 文档标题：30px 半粗，只属于文档画布，不进入工具栏；面板和设置页标题：16–20px 半粗。
- 正文与控件：13–14px；笔记正文 15px / 行高 1.75。
- 眉题 10px 大写、字距放宽；分组标题 11px 半粗；元信息、状态栏和快捷键提示：11–12px。
- 组内间距优先 8px，工具条横向间距 8–12px，页面内容区 24–40px。
- 长标题必须截断；状态文本应有上限，不允许把底层原始错误无限铺到界面。

## 5. 交互状态

- 当前活动项使用智能绿色或浅绿色底和明确图标色，不依赖颜色极细微变化。
- Hover 只改变浅背景或边框，不移动布局。
- 主操作每个局部区域最多一个；危险操作必须使用危险色并经过确认。
- 只读、不可用和平台降级必须显示真实原因，不提供无效按钮。
- 空工作台提供“新建文件 / 新建笔记 / 导入”这类下一步，不显示技术栈占位。
- 后台操作要区分运行中、成功、失败、取消和超时；迟到结果不得覆盖更新状态。书签元数据
  抓取这类锦上添花型后台任务允许完全静默，失败不得改动捕获本身的状态反馈。

## 6. 键盘与可访问性

- 搜索：`Ctrl/⌘ K`、`Ctrl/⌘ P`。
- 新建、保存、关闭标签：`Ctrl/⌘ N`、`Ctrl/⌘ S`、`Ctrl/⌘ W`。
- 标签循环：`Ctrl+Tab`、`Ctrl+Shift+Tab`。
- 侧边导航栏：`Alt+1` 切换项目活动栏，`Alt+2–5` 依次打开最近、浏览、应用和设置；重命名：
  `F2`；查找/替换：`Ctrl/⌘ F`、`Ctrl/⌘ Alt+F`。
- 笔记正文聚焦时提供粗体、斜体、删除线、行内代码、块移动和复制快捷键；具体映射见
  [desktop-editor.md](desktop-editor.md#快捷键)。
- 焦点顺序必须遵循顶栏 → 侧边导航栏 → 活动/目录栏 → 标签/编辑区。
- 键盘选择与鼠标选择使用同一状态；隐藏或折叠节点不得进入相对选择序列。
- 移动触摸目标不得小于 44px，并继续通过原生文本代理验证 IME 与辅助功能。

## 7. 组件规则

- `workbench/view.rs` 只组合工作台；组件专属状态、动作和纯逻辑进入对应目录。
- Editor、Explorer 与 Browser 的职责和挂载状态见
  [desktop-components.md](desktop-components.md)。
- SQLite、同步、Agent 和安全存储调用停留在 application/adapters 边界，不能下沉到纯视图。
- 跨桌面/移动共享的文案、导航和 Token 进入 `ideall-presentation`，不得共享 GPUI 类型。
- 新可见组件需要覆盖正常、空、加载、只读、失败和平台降级状态。
